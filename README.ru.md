# Must Rescue

Резервная копия публичного профиля Must и подготовка файлов для переноса фильмов в Letterboxd.

**[Открыть сайт →](https://vitali-ai.github.io/must-rescue/)** · [English](README.md)

## Как пользоваться

1. Скопируйте ссылку на свой профиль Must или ник. Профиль должен быть публичным; после выгрузки его можно снова закрыть.
2. Вставьте ссылку на сайте и нажмите «Получить файлы». Опция сезонов сохранит их оценки и прогресс, но потребует больше запросов.
3. Скачайте ZIP с резервной копией и проверьте предупреждения.
4. `letterboxd_watched.csv` загрузите на [основной странице импорта Letterboxd](https://letterboxd.com/import/): это просмотренные фильмы с оценками и доступными отзывами.
5. `letterboxd_watchlist.csv` загрузите **из своего Watchlist → Import films to watchlist**. Основной импорт пометит фильмы просмотренными!
6. Проверьте совпадения названий и годов до подтверждения импорта.

Все данные обрабатываются в вашем браузере. Приложение не запрашивает пароль, не изменяет аккаунты, не использует аналитику и не отправляет коллекцию на сервер приложения. GitHub обслуживает сайт, Must получает запросы к своему API.

## Что важно знать

- Списки Must могут содержать и фильмы, и сериалы. CSV для Letterboxd включает только фильмы. Сериалы, сезоны, их оценки и доступный прогресс сохраняются в ZIP отдельно.
- Оценки фильмов сохраняются по шкале из 10, Letterboxd переведёт их в звёзды.
- Дата изменения записи Must не равна дате просмотра. Мы не создаём фиктивные даты дневника.
- Фильмы сопоставляются по названию и году; точные IMDb/TMDB ID не определяются. Проверка совпадений при импорте необходима.
- В архиве `backup/verification.json` перечислены пропущенные ID и расхождения числа оценок. Полнота проверяется относительно публичных списков Must, а не возможной локальной истории приложения.
- Экспорт зависит от доступности Must и его политики CORS. 29 октября 2026 года сервер Must отвечал HTTP 522; свежую выгрузку через браузер пока не удалось проверить. Демо показывает только вымышленные записи.
- При сбое Must повторите позже. При блокировке браузером можно использовать CLI. Если уже есть `backup.json` от этой версии инструмента, откройте его на сайте и получите файлы без обращения к Must.

## Запуск на компьютере

Нужен Node.js 24+. Дополнительные библиотеки и ключи API не нужны.

```sh
git clone https://github.com/vitali-ai/must-rescue.git
cd must-rescue
node --use-env-proxy cli.mjs your-nickname --out exports
```

Без сезонов: добавьте `--no-seasons`. Повторное создание CSV без интернета:

```sh
node cli.mjs --from-backup exports/backup/backup.json --out regenerated
```

Для новой копии используйте новую папку: файлы в выбранной папке перезаписываются. В браузере выгрузка держится только в памяти, после закрытия вкладки останутся только скачанные вами файлы.

Код сайта находится в `docs/`; GitHub Pages публикует эту папку из ветки `main` без сборки. Тесты: `npm test` (для независимой проверки ZIP нужен Python 3). Подробнее об устройстве и ограничениях — в [README на английском](README.md).

Не прикрепляйте личные выгрузки и токены к публичным issues. В репозитории используются только вымышленные тестовые записи.

Независимый проект, не связан с Must и Letterboxd. Лицензия MIT.
