A few things worth knowing

What happens to my ratings and dates?

Personal movie ratings are saved out of ten; Letterboxd converts them to stars. Must provides a last-modified date, not a reliable viewing date, so we do not create diary entries using these dates. Available reviews are also preserved.

Why might the counts be different?

Must can put movies and TV shows in the same list. Letterboxd CSVs include movies only. Shows are retained separately in your backup. If the API omits records or the rating count differs from Must’s profile statistics, we show a warning.

What if Must is not responding?

Exporting depends on Must’s servers. If they are unavailable, try again later. Browser CORS restrictions can also block requests; the CLI on GitHub is an alternative. You can open a previously downloaded backup.json below without contacting Must.

Who sees my collection?

The app reads your public Must profile directly from your device. We ask for no password, use no analytics and do not save your collection on a server or in browser storage. GitHub hosts this site, and Must receives API requests. You can make your profile private again after exporting.
