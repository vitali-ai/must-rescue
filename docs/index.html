03

Импортируйте фильмы и watchlist отдельно. Сериалы и сезоны останутся в резервной копии.

Пара важных деталей

Что будет с моими оценками и датами?

Личные оценки фильмов сохраняются из 10; Letterboxd переводит их в звёзды. Must отдаёт дату изменения записи, а не надёжную дату просмотра, поэтому мы не создаём записи дневника с этими датами. Доступные отзывы тоже сохраняются.

Почему количество записей может отличаться?

В Must в одном списке могут находиться фильмы и сериалы. CSV для Letterboxd содержит только фильмы. Сериалы сохраняются отдельно в архиве. Если API не вернул часть записей или число оценок расходится со статистикой Must, мы покажем предупреждение.

Что делать, если Must не отвечает?

Экспорт зависит от серверов Must. Если они недоступны, повторите позже. Иногда браузер блокирует запросы из-за CORS; тогда можно использовать CLI из GitHub. Уже скачанный backup.json можно открыть ниже без запросов к Must.

Кто видит мою коллекцию?

Приложение читает публичный профиль Must напрямую с вашего устройства. Мы не запрашиваем пароль, не используем аналитику и не сохраняем коллекцию на сервере или в браузерном хранилище. GitHub обслуживает сайт, а Must получает запросы к своему API. После экспорта можно снова закрыть профиль.
